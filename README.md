# koskei.com

Personal landing page for [Kostiantyn Keilin](https://koskei.com) — Senior Front-End Engineer.

## Stack

Next.js (App Router) · TypeScript · React 19. No external UI library.

## Deploy

Hosted on Vercel. Deploys automatically on push to `main`.

1. Push changes to `main`
2. Vercel picks it up automatically

**Build command:** `next build`  
**Domain:** koskei.com

## Local dev

```bash
npm install
npm run dev
```
